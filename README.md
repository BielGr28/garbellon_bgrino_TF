**Unity Version:** 6000.3.6f1

Para comprovar el correcto funcionamiento del proyecto hasta ahora se recomienda consultar los siguentes apartados:

- La escena con el movimiento, armamento y mejoras se encuentra en la carpeta _SCENES_ con el nombre _Playground_.
- Todos los componentes de programación se encuentran en la carpeta _SCRIPTS_ --> _PLAYER_ las más importantes son las siguientes:
-   Movimiento: Se encuentra en la carpeta _CONTROLLER_
-   Armamento: Se encuentra en la carpeta _WEAPONS_
-   Mejoras: Las mejoras están divididas entre _scriptable objects_ y _scripts_ con su funcionamiento interno. Estan las dos en la carpeta _UPGRADES_
-   Experiéncia: La lógica del sistema de experiencia se encuentra en la carpeta _XP_
